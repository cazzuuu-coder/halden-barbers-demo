Work / Alto Detail

Concept project

Alto Detail

A showroom-like concept for a detailing studio: grey, oxide red, and cars photographed as objects in a bay. The site is five pages, including a results page built around before-and-after sliders.

View live demo Back to work

The brief

Build a complete detailing website with a distinct brand, priced packages, a visual comparison, and a contact path that does not invent results.

Objective

Show how WEBAUR would treat a technical service brand: photography, typography and a feature (the slider) that actually does something.

Audience

A detailing studio that wants to look as precise as the work — closer to a showroom than to a loud auto-shop advert.

This is a concept project. It is not a paying-client website, and it does not invent customers, reviews or results.

Key features

  • Five pages: home, services, results, process, contact
  • Three named packages with example prices
  • Interactive before-and-after sliders, honestly captioned
  • A process page that walks through a day in the bay

The sliders compare two treatments of the same photograph. They are illustrative, not proof of a paid job.

Design decisions

Give the brand a manufacturer’s voice.

Big Shoulders is wide and mechanical; Source Sans 3 keeps packages and process notes easy to read. Oxide red is used sparingly, like a painted brake caliper.

Make the comparison honest.

A slider is convincing only if the caption is true. Both sides are the same photograph; the “before” is a processed frame, and the page says so.

Put the price where the package is.

Essential, Signature and Atelier are listed with example figures so a visitor can judge the offering without a gate.
